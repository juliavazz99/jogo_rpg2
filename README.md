# 🟨 Backrooms - O Último Corredor

Jogo de aventura em texto desenvolvido em Python.

## Sobre o jogo

O jogador entra misteriosamente nas Backrooms e precisa
encontrar uma saída enquanto explora diferentes ambientes.

## Recursos

- Escolhas do jogador
- História ramificada
- Inventário
- Sistema de vida
- 7 cenas
- 3 finais diferentes
- Funções em Python
- Estrutura de repetição while
